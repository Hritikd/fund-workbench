# Code of Conduct

We want a practical, respectful community focused on making evidence workflows more reliable.

Participants must communicate constructively, respect privacy, accept good-faith correction, and avoid harassment or discrimination. Do not post confidential company information, credentials, personal data, or materials you lack permission to share.

Project maintainers may edit or remove material that violates these expectations and may restrict participation when necessary to protect the community.

Report conduct or security concerns privately through the repository owner’s GitHub profile rather than opening a public issue containing sensitive information.
