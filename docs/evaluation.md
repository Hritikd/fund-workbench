# Evaluation protocol

Use this protocol before claiming that Fund Workbench improves efficiency or quality.

## Dataset

Create at least 20 synthetic or authorized cases representing different sectors and document quality. For each case, keep a reviewer-approved reference set of material claims, evidence statuses, conflicts, and required follow-up questions.

## Compare two workflows

1. Manual review using the team’s current process.
2. Fund Workbench followed by human review and correction.

Randomize case order and avoid having the same reviewer build the reference set and evaluate every output.

## Measures

- Minutes from receipt to a reviewable brief
- Reference claims captured
- Unsupported claims promoted as facts
- Source IDs and quotes preserved correctly
- Known contradictions surfaced
- Reviewer edits before acceptance
- Diligence questions accepted as useful
- Follow-up actions with an owner and date

## Reporting

Report sample size, medians, ranges, and the exact model/configuration. Separate extraction time from human review time. Do not generalize results from the synthetic demo to real investment quality.
